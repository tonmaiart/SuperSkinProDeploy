# Super Skin Pro

Professional weight painting layers system for Blender.

Super Skin Pro brings a non-destructive, layer-based workflow to weight painting, together with a set of skinning tools for editing, mirroring, and transferring vertex weights.

## Requirements

- Blender 4.2 or newer
